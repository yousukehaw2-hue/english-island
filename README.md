# English Island

中学1年生から約1年で英検準2級を目指す、島育成型の英語学習PWAです。

## v0.2
- Smartphone-first UI
- Vocabulary / Grammar / Review demo quest
- Stars / Island Level / vocabulary plant growth
- Journey / My Page
- Local device save
- PWA manifest + service worker + offline cache
- GitHub Pages compatible

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) を選択すると公開できます。

## Data
v0.2は学習データをブラウザのlocalStorageに保存します。Supabase同期は後続版で追加予定です。

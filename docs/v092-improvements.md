# English Island v0.9.2

改善1〜4を反映。

| 改善 | 実装 |
|---|---|
| 1 正答・選択肢 | 時制や意味の指定で競合する正答を修正。出題時に選択肢・正答・診断タグ・誤答解説を一緒にシャッフル。 |
| 2 個別解説 | 元の105問の汎用解説を、文法規則・音声や本文の根拠に置換。選択した誤答と対応する説明を表示。 |
| 3 知識別ペア | 271問を98対象へ接続。単語60、文法24、Listening8、Reading6。各対象に基礎問題と別文脈の問題を用意。 |
| 4 適応復習 | 選んだ誤答の診断を保存。基礎再確認→別文脈の確認をDaily Questへ反映。前提知識・学年範囲・復習期限・最近の出題を考慮。 |

既存のStars、島の成長、学習履歴は保持。対象別の確認状況は新たに記録し、既存の得点から確認済みとは判定しない。

新規開始直後は前提知識を満たす問題だけを選ぶため、目標12問より少ない7問になる。基礎正答により次のQuestの選択肢が広がる。同一Questには同じ学習対象を重複させない。

教材再レビューはKEEP230、REVISE41、REPLACE0。41問は級相当の難易度確認が残る。学年・英検級は内部の目安であり公式対応ではない。Writing・Speakingの7 Skillは未収録。別文脈の1回の正答は、長期習得を保証しない。

検証: 82回帰項目、36適応学習項目、実際の画面スクリプトを使った選択肢・誤答説明・保存・復習接続・島の成長テスト。実ブラウザでのレイアウト確認は未実施。
